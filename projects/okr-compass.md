# OKR Compass

A mobile-first Progressive Web App for tracking objectives and key results, daily habits and personal goals.

**Status:** early stage · **Repo:** private

## Highlights

- Installable PWA with a mobile-first interface.
- Authentication and cloud data through Firebase.
- Analytics views, data-layer services and end-to-end tests for authentication and core features.

## Technology

Next.js (App Router), TypeScript, Tailwind CSS, Firebase.
