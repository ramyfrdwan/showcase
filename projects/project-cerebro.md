# Project Cerebro

An AI-powered marketing-operations agent platform that moves teams from monitoring dashboards to proactive problem solving.

**Status:** deployed · **Repo:** private

## What it does

Automates extraction, analysis and documentation of marketing tracking and analytics work, and surfaces issues with proposed fixes instead of only charts.

## Highlights

- Full-stack TypeScript platform with an API layer, background services and a companion mobile app.
- Cloud-native deployment on Google Cloud Run, with infrastructure as code.
- Strong quality gates: strict typing, architecture-boundary checks, unit, regression, smoke and end-to-end suites.
- Secret scanning and security checks wired into commit and CI.

## Technology

Next.js 16, React 19, TypeScript, NestJS, Prisma, PostgreSQL, Flutter, Terraform, Docker, Cloud Run, Vitest, Playwright.
